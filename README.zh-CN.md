# 此刻 · Here

**不必等到更强大。**

此刻是一个面向性骚扰与性暴力经历者的全球支持工作台前端原型，帮助用户按自己的节奏寻找支持、记录经历，并准备下一步。

界面默认英语，可切换简体中文。适配手机与桌面，无依赖、无构建步骤。

### 功能

- 四个页面：从这里开始、寻找支持、记录我的经历、我的下一步。
- 当前所在地与事件发生地分别填写。地区仅改变演示标签，不执行真实的本地资源匹配。
- 支持类别筛选、中英文关键词搜索、加载状态与空结果提示。
- 当前会话记录、清除前确认与文本下载。
- 三种草稿目标：了解支持与咨询、准备投诉或报案咨询、申请生活安排调整。
- 可编辑的双语草稿模板，以及核对后的模拟提交结果预览。
- 隐私说明、语义导航、键盘焦点与小猫 Logo。

### 本地预览

直接打开 `index.html`，或使用任意静态文件服务器运行此目录。页面使用 URL hash 导航，资源路径均为相对路径，适用于 GitHub Pages 项目子路径。

### 发布到 GitHub Pages

1. 将 `index.html`、`styles.css`、`i18n.js`、`app.js`、`mock-api.js`、`logo-cat.png` 和 `.nojekyll` 放在仓库根目录。
2. 打开 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**。
3. 选择 `main` 分支与 `/ (root)`，保存。
4. 等待部署完成，打开 GitHub Pages 提供的地址。对于 `erinirex/here` 仓库，启用 Pages 且部署成功后的项目地址为 `https://erinirex.github.io/here/`。

### 接入真实 API

`mock-api.js` 提供 `searchResources`、`prepareDraft`、`simulateSubmission` 三个异步方法，目前完全在浏览器中运行，不发起后端请求。

接入真实服务时使用后端代理，不要将 API 密钥写入前端文件或仓库。替换模拟提交前，应实现接收方选择、资料披露范围控制、明确授权、重复提交保护与准确的回执状态。资源需独立核验来源、当地适用性和有效期。本原型不包含真实法律或医疗服务目录。

### 语言行为

切换语言会保留表单内容，不会自动翻译原始记录或已编辑的草稿。新草稿使用开始生成时的界面语言。如需另一种语言的模板，可切换后重新生成；重新生成会替换现有草稿及其修改。

语言偏好不持久化，刷新后恢复英语。

### 隐私与限制

输入仅保留在 JavaScript 内存中。应用不使用 localStorage、Cookie、数据库、分析追踪或网络上传来保存输入。刷新或关闭页面会清除会话记录。用户主动下载的文件会保留在设备上。托管平台仍可能记录普通访问日志。

所有资源卡片均明确标注为占位。搜索、草稿生成与提交均为模拟。没有真实 AI、翻译服务、账户系统、附件上传、紧急呼叫或机构对接。本原型不用于处理真实个案或提供紧急救援。

支持 `document.modelContext` 的浏览器可以提供页面内导航工具，不暴露读取私人记录或提交的工具；其他浏览器可正常使用。
