# GoatCounter statistics

## English

Configured site: https://erinxia.goatcounter.com/ — no Node.js, Cloudflare or API secret is needed for this integration.

1. In GoatCounter site settings enable **Allow adding visitor counts on your website**. Keep the full dashboard private unless you intend to publish it.
2. Push the changed files to GitHub and wait for Pages deployment.
3. Open the published website; statistics start automatically unless previously turned off. Local previews and DNT/GPC visits are excluded. If the script is blocked, the website still works.
4. Inspect the dashboard for the fixed page /here and event click. Public counters may be unavailable until enabled and the first event is processed.
5. README and stats.html display public view/click images. Images may cache for up to four hours plus GitHub caching: they are not real-time. Unique visitor estimates are available in the dashboard, not the public count endpoint. Do not label views as unique people.

The script loads by default, unless previously turned off or blocked by DNT/GPC. Our code sends no narratives, form values, region choices, search terms, resource labels or actual page/referrer URLs. GoatCounter still receives network and device information and estimates visitors under its own privacy policy. In its settings disable location, referrer and device breakdowns if not needed. The on/off preference is stored locally; no daily browser ID is generated by this integration. Use Turn off statistics in the footer to stop. Opting out does not delete past aggregate counts. DNT/GPC always blocks collection. Existing GoatCounter opt-outs remain respected. There is no consent prompt.

Clicks are generic button/link events, limited to one per 500ms and 200 per page. Counts are approximate, affected by filtering, blockers and bots. No API token belongs in frontend code. Set HERE_GOATCOUNTER_ENDPOINT to an empty string to disable future loads; already open pages must be refreshed.

The older worker.mjs, schema.sql, wrangler.toml and configure.mjs are inactive legacy Cloudflare files. Do not run configure.mjs for this setup.

References: [JavaScript API](https://www.goatcounter.com/help/js), [public counters](https://www.goatcounter.com/help/visitor-counter).

## 简体中文

已接入 https://erinxia.goatcounter.com/ ，本方案无需 Node.js、Cloudflare 或 API 密钥。

1. 在 GoatCounter 网站设置中启用 **Allow adding visitor counts on your website**（允许公开计数）。无需公开完整统计后台。
2. 将修改推送到 GitHub，等待 Pages 发布。
3. 打开线上网站即可自动统计，之前已关闭统计的浏览器除外。本地预览和启用 DNT/GPC 的访问不计数；统计被拦截不影响网站功能。
4. 在后台查看固定页面 /here 和事件 click。公开计数可能要启用后且有首条数据才可用。
5. README 和 stats.html 展示访问、点击计数。图片最多缓存 4 小时，GitHub 可能另有延迟，不是实时数字。去重访客估算在后台查看，公开计数不能冒充独立人数。

默认加载服务，已关闭统计或启用 DNT/GPC 时不加载。不发送经历、表单内容、地区选择、搜索词、资源名称或实际页面与来源链接。GoatCounter 仍会接收网络、设备信息并按其规则估算访客；建议在后台关闭不需要的地区、来源和设备细分统计。本站仅保存统计开关选择，不再生成每日浏览器标识。不显示同意弹窗，已有关闭选择继续有效，可通过页脚“关闭统计”停止；停止不会删除已有汇总计数，DNT/GPC 始终阻止采集。

点击仅按通用按钮/链接事件统计，每 500 毫秒最多一次，每次页面加载最多 200 次。数据受拦截、过滤及机器人影响，只是估算。无需把任何 API Token 放入代码。将 analytics-config.js 中的 HERE_GOATCOUNTER_ENDPOINT 设为空字符串可停止后续加载，已打开页面需刷新。

旧 Cloudflare 文件保留但不启用，不要运行 configure.mjs。统计代码已配置不代表已经发布；需要 git push 后等待网站部署。
